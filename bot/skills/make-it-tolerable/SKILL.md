# Make it tolerable

## A. "Can you do it for just 10 minutes?"
- "Yeah, that sounds doable" → *"Hell yeah, get started!"* (Offer a 10-minute check-in, only if they say yes.)
- "That still sounds bad" → **"Why?"**
  - "It's an unpleasant or arduous task" → section B *(most likely routing)*
  - "I'm worried I'll fail." → **"Go to Step 4."** → **extension-or-delegate** *(most likely routing)*. *Bot note:* worry about failing is also handled well by **break-it-down**, so you may offer it as an option.

## B. MAKE IT MORE TOLERABLE
Offer up to 3:

| Chart bullet | Evidence (tip) | Bot tip (not chart text) |
|---|---|---|
| **Listen** to music or an audiobook | weak | For reading/writing, white or pink noise fits better |
| **Accomodate the task** [sic] to make it less bad | weak | Pair the chore with something you enjoy |
| **Pretend to be excited** about it, **find the fun** | weak | |
| **Decide on a reward** for after | partly contradicted | Small, frequent rewards close to the effort |
| **Change of scenery** | none | Outdoors or near greenery if possible |
| **Wear the "Scientist Hat"**- they do this task! | weak | "Be the kind of person who does this" |
| **Body double** with a friend | none (popular, low-risk) | Suits simple tasks best |

Outcomes:
- "One of those worked!" → *"Hell yeah, get started!"*
- "This didn't help" → section C.

## C. DIY DOPAMINE (from B, or from interrupt-inertia)
Frame this as a **quick mood or energy reset**, not brain chemistry (evidence_review.md A3).

| Chart bullet | Evidence (tip) |
|---|---|
| **Dance break** with fun song | none for starting tasks |
| **Delicious snack** | contradicted as a willpower boost. Offer it only if they're hungry |
| **Exercise:** 60s jumping jacks | weak (studied doses are 10–30 min). Keep it optional and gentle |
| **Stretch** | none (harmless) |
| **Novelty** (position, environs) | none |

Outcomes:
- "I can start the task now!" → *"Hell yeah, get started!"*
- "It isn't helping" → **extension-or-delegate** (Step ④).

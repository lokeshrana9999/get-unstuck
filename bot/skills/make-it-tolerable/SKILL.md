# Make it tolerable

## A. "Could you give it 10 minutes? Only 10, and then you're allowed to stop."
- "Yeah, that sounds doable" → *"Hell yeah, get started!"* (Offer a 10-minute check-in, only if they say yes.)
- "That still sounds bad" → **"Why?"**
  - "It's an unpleasant or arduous task" → section B *(most likely routing)*
  - "I'm worried I'll fail." → **break-it-down** (bot reroute; the chart sends this to Step ④). Low confidence is one of the strongest drivers of procrastination (B6), so shrink the task and offer a "good enough" version early.

## B. MAKE IT MORE TOLERABLE
Offer up to 3:

| Bot wording | Honesty tag |
|---|---|
| Try white or pink noise. Save music with lyrics and audiobooks for tasks that don't involve words, or as a treat you only get while doing the chore. | reasonable but untested |
| Accommodate the task to make it less bad, e.g. pair it with something you enjoy that you only get while doing it. | reasonable but untested |
| Set small rewards you get during and right after each step. | reasonable but untested |
| Body double with a friend (works for many people; not tested in trials yet; best for routine tasks). | reasonable but untested |
| Pretend to be excited about it, find the fun | a hack some people like |
| Change of scenery | a hack some people like |
| Wear the "Scientist Hat"- they do this task! | a hack some people like |

Outcomes:
- "One of those worked!" → *"Hell yeah, get started!"*
- "This didn't help" → section C.

## C. QUICK RESET (chart: DIY DOPAMINE)
Frame this as a **quick reset** of mood or energy. Never use the word "dopamine" (A3). Movement is only suggested if it's safe for the person's body.

| Bot wording | Honesty tag |
|---|---|
| Move for 10-20 minutes if you can (a walk, jumping jacks); even a minute is a start. Only if it's safe for your body. | reasonable but untested |
| Dance break with a fun song (if moving feels okay for your body). | a hack some people like |
| Stretch, gently and only in ways that feel okay. | a hack some people like |
| Novelty (position, environs) | a hack some people like |

Dropped: "Delicious snack". Snacks don't boost willpower (E2). Hunger is handled in **wellbeing-check**.

Outcomes:
- "I can start the task now!" → *"Hell yeah, get started!"*
- "It isn't helping" → **extension-or-delegate** (Step ④).

# Interrupt inertia

Offer **up to 3** at a time, top of the list first, and let the person choose. The wording below is the bot version from the `bot` overlays in `data/flowchart.json`; the original chart text stays in the data. Show the honesty tag in plain words.

| Bot wording | Honesty tag |
|---|---|
| Put on content blocker | well supported |
| Create an interruption: a content blocker, or a timer across the room. | reasonable but untested |
| Stop what you're doing for 5 minutes. | reasonable but untested |
| Set a check-in alarm (you choose how often): do you want to be doing this? | reasonable but untested (counts toward the ≤ 3 check-ins/day cap) |
| Ask someone to interrupt you. I can draft the message; you send it. | reasonable but untested |
| Set up accountability from others | reasonable but untested |
| Drink a glass of water so you'll get up soon (skip this if you've been told to limit fluids). | a hack some people like |
| Get into an uncomfortable position so you're more likely to get up | a hack some people like |
| Make grumbling noises about it | a hack some people like (harmless, fun) |
| Pretend you're teaching someone ADHD skills & verbally explain how you overcome paralysis | a hack some people like |

## Outcomes
- "I got unstuck from the task, but still need help starting." → **make-it-tolerable**, QUICK RESET section.
- "I can start the task now!" → *"Hell yeah, get started!"*
- "These didn't help" → **"Try this instead: set a timer or alarm across the room, so you have to get up to stop it. Then go to Step 4."** → **extension-or-delegate**.
  - The chart's "toss phone across room, knock over water" is **never** suggested (guardrails §4).

# Interrupt inertia

Offer **up to 3** of these at a time and let the person choose. Chart bullets, with evidence levels from `data/flowchart.json`:

| Chart bullet | Evidence (tip) |
|---|---|
| **Create interruptions:** drinking lots of water, content blockers, etc | none / blockers moderate |
| **Stop what you're doing for just 5 minutes** | not separately reviewed |
| **Drink water** so you get up to pee | none. ⚠ Not for anyone on fluid restrictions |
| **Put on content blocker** | moderate (general population) |
| **Get into an uncomfortable position** so you're more likely to get up | none |
| **Set a recurring alarm** to check in: do you want to be doing this? | weak-moderate. Can offer routine R3 (with a yes) |
| **Ask for help** to interrupt task | weak. The bot may *draft* a message; it never sends one |
| **Set up accountability** from others | weak |
| **Make grumbling noises** about it | none (harmless, fun) |
| **Pretend you're teaching** someone ADHD skills & verbally explain how you overcome paralysis | none for starting tasks |

Good first picks: content blocker, stop for 5 minutes, or a check-in alarm.

## Outcomes
- "I got unstuck from the task, but still need help starting." → **make-it-tolerable** (DIY DOPAMINE section).
- "I can start the task now!" → *"Hell yeah, get started!"*
- "These didn't help" → the chart says **"Create a harmless but immediate problem (toss phone across room, knock over water) Go to step 4."**
  - **Guardrail:** don't suggest throwing phones or spilling water. Offer the safe version instead: *"Put a timer across the room for 2 minutes, so you have to get up to stop it."* Then go to **extension-or-delegate** (Step ④).

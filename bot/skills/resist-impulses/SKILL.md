# Resist impulses

**Treat this as mostly friction, not willpower** (verdict §4e.8; evidence_review.md G2, G5, G6, F4). Offer up to 3 from the top of the list first.

| Bot wording | Honesty tag |
|---|---|
| Create physical distance from the thing | well supported |
| Make it harder to follow impulse- delete apps, hide things, etc. | well supported |
| Find an out: add a natural stopping point, e.g. set a content blocker to start in 15 minutes. | well supported |
| Plan an interruption or ask a friend for help interrupting. (I can draft the message; you send it.) | well supported |
| Set up accountability with others | reasonable but untested |
| Set a check-in alarm (you choose how often) | reasonable but untested |
| Name the emotion, impulse, and need. "I'm feeling grumpy, so I want to give up. I need to have a snack and take a break." | reasonable but untested |
| Create a gap: wait 5 minutes before acting on the urge. | reasonable but untested |
| Look forward : "How will I feel if I follow X impulse?" … and if I don't? | reasonable but untested |
| Swap the reward: trade the open-ended treat for a short, contained one you get right after a bit of the task. | reasonable but untested |
| Pretend you're teaching someone ADHD skills & verbally explain how you resist impulses | a hack some people like |

Dropped from the bot version: "Look back" (no support, and a hint it doesn't work) and the DBT willfulness worksheet (no study; it only makes sense inside a DBT course).

## Outcomes
- "One of those worked!" → *"Hell yeah, get started!"*
- "I'm sort of resisting the impulse, but not starting the task." → **interrupt-inertia** *(most likely routing)*
- "I still can't resist, I really really want to do the thing" → **a one-round comic exchange** *(most likely routing; shortened in the bot)*:
  1. Bot: "Go to Step 4?" (gently, with a smile)
  2. If they agree → **extension-or-delegate**.
  3. If they refuse ("I don't want to, I really want to do this thing instead…") → Bot: "Fine." → **"Practice radical acceptance.** This task may not get done right now. It might feel like a catastrophe, but it'll be okay." Then offer a when-and-where plan for later.

Never argue more than one round. If the person seems distressed rather than playful, skip the joke and offer **wellbeing-check**.

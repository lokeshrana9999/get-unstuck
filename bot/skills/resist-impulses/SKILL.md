# Resist impulses

Start with **naming**, then offer up to 3 more. Chart bullets:

| Chart bullet (abridged) | Evidence (tip) |
|---|---|
| **Name the emotion, impulse, and need.** "I'm feeling grumpy, so I want to give up. I need to have a snack and take a break." | weak (affect labelling: moderate in lab) |
| **Create physical distance** from the thing | moderate |
| **Create a gap.** Wait just 5 minutes before acting. | none |
| **Look back:** last time you acted on this impulse ("Last time I ___, I felt ___ / ____ happened") | none |
| **Look forward :** "How will I feel if I follow X impulse?" … and if I don't? | moderate (lab) |
| **Find an out:** add a natural stopping point (water ⚠, a content blocker in 15 min) | moderate (child ADHD lab) |
| **Plan an interruption** or ask a friend for help interrupting | moderate |
| **Make it harder** to follow impulse: delete apps, hide things, etc. | moderate |
| **Set a recurring alarm** to check in | weak-moderate |
| **Set up accountability** with others | weak |
| **Follow the dopamine** and replace it with something shorter/more contained | none. Describe it as "swap for a smaller, quicker treat"; avoid dopamine talk |
| **Pretend you're teaching** someone how you resist impulses | none |

Strongest picks: physical distance, make it harder, find an out.

## Outcomes
- "One of those worked!" → *"Hell yeah, get started!"*
- "I'm sort of resisting the impulse, but not starting the task." → **interrupt-inertia** *(most likely routing)*
- "I still can't resist, I really really want to do the thing" → the comic exchange *(most likely routing)*. Play it gently and with humor. At each line, the person can agree and go to Step ④:
  1. Bot: "Go to Step 4."
  2. Person: "I don't want to, I really want to do this thing instead and I don't want to bother with skills."
  3. Bot: "Do DBT worksheet on **willfulness.** Go to Step 4." *(pointer only; evidence: none)*
  4. Person: "I don't want to!!"
  5. Bot: "Please go to Step 4?"
  6. Person: "No!!!"
  7. Bot: "Fine."
  8. → **"Practice radical acceptance.** This task may not get done right now. It might feel like a catastrophe, but it'll be okay." (shared with **extension-or-delegate**)

Never let the humor shame the person. If they seem genuinely distressed rather than playful, skip the comic lines and offer **wellbeing-check**.

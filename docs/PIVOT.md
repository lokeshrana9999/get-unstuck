# Pivot (from Lokesh, 31 Oct 2026)

Shift from a "get unstuck when stuck" helper to a full **productivity bot for ADHD people**: it uses the flowchart logic and the evidence review to help people actually get things done.

- During setup, the bot asks the user what they want to accomplish (goals, recurring tasks, deadlines) and when and how they want reminders.
- It uses Grok Bot scheduled messages / routines for proactive check-ins, start nudges, body-doubling style sessions, and end-of-day reviews.
- The flowchart becomes the in-the-moment engine when a check-in finds the user stuck.
